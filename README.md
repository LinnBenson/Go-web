# Go web

面向 Android 手表的单页浏览器，包名 `io.todu.goweb`。内置 Mozilla GeckoView，不依赖设备的系统 WebView。

## 使用

- 启动时打开 Google，可在菜单中修改启动网址。
- 网页滚动到顶部后继续下拉，顶部会弹性伸展；圆环填满后松手打开菜单，未到阈值则回弹。
- 菜单左右滑动分页，每页最多六项，下方圆点标示当前页。第一页为主页、刷新、清缓存、打开 URL、书签、密码本；第二页为下载、启动网址、软件信息。上方弧形控件调整缩放。底部弧形条调整视口高度，上滑菜单超过阈值后松手关闭，长按图标可查看名称。
- 书签列表可添加当前网页并点击打开，书签保存在本机，重复网址不会重复添加；长按书签可编辑标题、网址或删除。书签和启动网址页面统一采用固定顶部标题、底部图标操作的圆屏布局，中间内容独立滚动。
- 菜单上滑超过阈值并松手即可退出；不足阈值则弹回。
- 菜单中调整整页缩放（20%–200%）、设置启动网址、刷新或回到主页。
- 从屏幕左侧中段约 20dp 的窄区域向右滑动，返回上一页。

加载进度沿表盘内缘以细圆弧显示，完成后自动隐藏；快速命中缓存时避免闪现进度条。

网页按设备可用显示区域布局，菜单覆盖在网页上，不压缩网页高度。Cookie 和网站本地存储保留，以支持登录与网页应用。

启动时显示原生加载动画，网页首次显示后立即退出动画，不人为延长等待。

启动页的 HTML、脚本、样式、图片（包括 SVG）和字体（包括 WOFF、WOFF2、TTF、OTF）使用持久 HTTP 缓存；通过 fetch、预加载或 object 加载且文件名与响应类型匹配的静态资源也纳入缓存，动态接口按网站原有请求与缓存策略处理；手动刷新会绕过旧缓存重新获取页面资源。其他网页遵循网站自身的 HTTP 缓存规则，保留缓存有效期和条件请求验证。更换启动网址会清理旧 HTTP 缓存，不清除登录信息。菜单中确认清除后，会清除全部网页缓存、Cookie、网站本地存储及登录认证记录，并重置各域名的缩放和高度设置；书签、启动网址及本地密码本保留。

缓存容量为 256 MiB。超过容量、网站使用不可缓存的响应变体、网站自行管理 Service Worker 缓存或设备清除应用数据时，不能保证所有资源一直保留；第三方网站的动态接口、登录验证和部分媒体仍需要网络。网站可能限制嵌入式浏览器登录。Google 的可访问性取决于设备网络。

## 安装

要求 Android 8.0 或更高版本。手表发布包使用 `armeabi-v7a`；仅支持 64 位的模拟器使用单独的 `arm64-v8a` 本地安装包。独立内核会增加安装包和运行内存占用。原生库在 APK 内压缩，安装时解压，启动时直接加载解压后的库；安装后的占用不会随 APK 大小同比缩小。

## 构建

使用 JDK 17、Android SDK 37.2 和 Gradle Wrapper：

```sh
./gradlew :app:assembleRelease
```

正式签名由外部密钥目录提供，不放入源码仓库。使用 `scripts/package_release.py --help` 查看签名和打包参数。发布 ZIP 只包含 32 位 APK 和 `SHA256SUMS.txt`。

## 第三方组件

浏览内核为 [Mozilla GeckoView](https://mozilla.github.io/geckoview/)，遵循 [MPL 2.0](https://www.mozilla.org/MPL/2.0/)。对应源码及其他依赖说明见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

缓存只复用静态文件，不保存 JS 执行结果、不替换 fetch/XHR、不改变定时器。每次打开页面仍由浏览内核正常执行脚本，JSONP、POST 和动态接口响应保持原样。

从屏幕右侧 8% 宽度的边缘区域左滑可切换圆屏留白：网页顶部、底部可露出带图标的半屏黑色原生区块，便于将边缘内容移到屏幕中央。再次左滑关闭，打开新页面时恢复默认。区块不写入网页 DOM，不改变网页布局高度。滚到文档底部后继续上滑可露出底部区块；使用独立内部滚动区域的网站可能无法自动识别底部。

网页中的返回右滑仅接受从屏幕左侧 8% 宽度区域起手的手势；页面中部横滑交给网站处理。

菜单上方弧形条调整网页缩放（20%–200%），下方调整浏览器视口高度（100%–300%），均以 10% 为一档，可横向拖动或点两端加减，松手应用。缩放默认 70%，视口高度默认 100%，按完整域名分别保存，不同子域名独立设置。高度使用原生浏览器布局尺寸，CSS vh 和 JS 窗口高度由引擎计算，不覆写网页的窗口 API；超出表盘的视口可上下拖动浏览，到边缘后继续滑动网页。screen.height 仍表示设备屏幕尺寸。清除缓存需确认，并重置所有域名的缩放、高度设置，保留书签和启动网址。

账号管理器目前提供本地密码本。首次进入设置并确认 8 位数字密码，数字和退格键沿圆环排列；解锁后可添加、查看、编辑、删除账号，密码默认隐藏。离开应用会锁定，清除网页缓存不会删除密码本。记录使用 PIN 派生密钥与 Android Keystore 双层加密，仅保存在当前安装中，不提供同步。请牢记主密码；忘记密码、卸载应用或清除应用数据后无法恢复记录。

网页密码框获得焦点时会显示密码本图标。点击并验证 PIN 后，可选择账号填入用户名、邮箱或手机号及密码；页面只有密码框时只填密码，不自动提交。验证期间页面跳转或表单发生变化后，需要重新选择。非标准自绘输入框可能不支持。

书签和密码本条目支持长按拖动排序，靠近列表上下边缘可自动滚动，松手保存顺序。长按后不拖动直接松手，仍可打开编辑、删除选项。

书签左侧显示网站图标，按比例完整显示；未找到或加载失败时显示标题首字。图标从网站直接获取并缓存在本机，“清除缓存”会一起清除图标缓存。

BlueStacks 使用软件 WebRender 兼容模拟器图形驱动，避免部分冷启动出现红色画面；真实设备仍使用默认渲染配置。

支持表盘复杂功能快捷入口：在表盘编辑器中选择支持图标或小图片的槽位，数据源选择 Go web，点击 G 图标即可打开应用。图标为透明背景单色图形；实际大小与颜色由表盘控制，不支持图像类型的槽位可能无法选择此入口。

网页下载会先确认，再保存到手表公开的 Download 文件夹。Android 9 及以下需授予存储权限；Android 10 及以上通过系统下载目录接口保存。下载管理器可查看进度、取消、打开或删除文件，“清除缓存”也会删除下载记录及对应的下载文件、上传临时副本，不删除 Download 中其他应用的文件。下载仅在应用前台进行，切到后台即取消，不会为下载持续保活；目前不支持断点续传，需回到网站重新下载。

网页上传通过系统文件选择器授权读取公开文件，可单选、多选或按网页要求选择文件夹。默认定位 Download，实际可选范围由系统决定。所选文件通过授权读取后暂存到应用缓存供浏览器上传，需要相应的可用存储空间；临时副本在浏览会话结束后清理。设备需提供系统文件选择器；直接拍照、录音上传暂未接入。上传选择器与文件打开界面由系统提供，其外观可能与应用页面不同。

应用没有开机自启动或定时唤醒任务。离开前台且没有输入、录音或待返回的系统选择器交互时，30 秒后结束浏览会话并释放浏览进程；再次打开会重新加载启动页，未提交的网页内容不会保留。系统键盘输入、应用发起的系统选择器及内核报告的录音状态会暂停回收计时。表盘快捷入口在独立轻量进程中提供图标，不初始化浏览内核。
