# 浏览器结构

应用使用原生 Android 界面承载一个 GeckoSession。GeckoRuntime 在浏览进程内复用，浏览器采用 TextureView 后端，避免调整视口高度时替换绘制表面。原生库按 ABI 分包并在 APK 中压缩，安装时由系统解压。

## 启动和页面配置

启动先显示原生加载动画，后台读取本地设置并准备内核配置。扩展连接及配置确认后加载启动网址。首次内容绘制后隐藏加载层；返回已经加载完成的启动页时避免重复导航。

缩放默认 70%，范围 20%–200%；视口高度默认 100%，范围 100%–300%，均以 10% 调整。设置按完整 host 保存，不合并子域名。高度通过原生视口尺寸实现，不覆写网页窗口 API。

## 缓存

内置扩展仅为启动页符合资源类型和响应条件的 HTML、脚本、样式、图片、字体等静态响应设置持久缓存策略。普通页面遵循站点的 HTTP 缓存策略。动态接口、POST、JSONP 及错误响应不纳入强缓存，不替换响应内容或 JS 执行结果。

网络缓存容量为 256 MiB。清理通过 Gecko StorageController 清除缓存、Cookie、网站存储及认证状态，并重置域名显示设置；本地图标缓存、下载记录及对应下载文件、上传临时文件一并清理，书签和密码本保留。

## 原生界面与手势

菜单为每页六项的圆屏布局，上下弧形控件分别调整缩放与视口高度。顶部继续下拉及菜单上滑使用阈值与回弹。左边缘右滑返回或退出，右边缘左滑切换上下原生留白，不向网页插入区块。

书签图标使用 256 KiB 内存缓存与本地文件缓存；磁盘图片解码前检查 64×64 尺寸，过期任务跳过，工作线程空闲 30 秒后退出；列表只填充可见行。拖动排序通过稳定行布局与位移实现。页面滚动状态观察按间隔合并，隐藏页面停止无效上报。

## 文件传输

下载由受限并发工作线程流式写入公开 Download。Android 10 起使用 MediaStore，旧系统请求存储权限。记录由 AtomicFile 保存。下载只在应用前台运行，后台取消，不自动恢复或重试。

上传使用系统文件选择器授予的 URI 读取权限，在后台将所选内容暂存为内核可读文件，避免直接使用无权读取的公共磁盘路径。读取使用固定大小缓冲区；取消、清缓存及浏览会话销毁时清理临时副本。

## 生命周期

Application 跟踪所有 Activity 的可见状态。离开前台后取消下载；无系统输入、待返回选择器或内核报告的录音交互时，经过 30 秒结束 Activity 并释放浏览进程。恢复前台或受保护交互会重置计时。结束进程后再次打开会重新加载启动页。

应用没有开机启动接收器或定时唤醒任务。下载服务使用 START_NOT_STICKY。表盘快捷入口在独立的轻量进程中提供静态图标，不创建 GeckoRuntime。

GeckoView 管理浏览会话的活跃状态及显示连接，Activity 不额外调用 setActive，也不在界面返回时解绑或重绑会话。浏览进程优先级由 Application 统一维护：任一应用 Activity 可见或有受保护交互时保留高优先级，全部离开后才降低。后台判定延迟 700 毫秒以跨过界面切换；恢复前台立即取消退出计时。密码本仍为独立 Activity，下载及书签等使用 Dialog，两者都不触发应用后台回收。

移除自动会话重建循环。内核异常结束时记录不含网页或凭据的状态，由用户点击重试重新创建界面。账号填充前检查会话仍打开。

## 页面辅助资源

保留 GeckoView 的启动预热、Android 默认备用进程配置、站点隔离及历史页面缓存。页面离开时断开应用的尺寸观察器，历史返回时恢复；填充授权沿用三分钟有效期，过期或取消后释放表单引用。会话关闭时删除扩展中对应的启动页缓存标记，不清除网页缓存内容。

内置扩展脚本变更时同步提升 manifest.json 的扩展版本；ensureBuiltIn 按版本判断更新，避免覆盖安装后复用旧版本注册状态。

点击首页图标时清理当前会话的导航历史，并以替换历史方式载入首页；保留 Cookie 和网络缓存。无上一页时右滑执行显式退出：取消下载、结束 Activity，由 onDestroy 关闭会话，随后释放浏览进程。若用户立即重新打开，前台回调取消待执行的进程释放。普通切到后台仍沿用保护交互与延迟退出规则。
